# تطبيق طبيب 24/7 لنظام Android

هذا مجلد مستقل لتطبيق Android بواجهة أصلية مبنية باستخدام Kotlin وJetpack Compose؛ لا يستخدم WebView، وتبقى صفحات الموقع الأصلية في جذر المستودع دون تغيير.

## فتح وبناء التطبيق

1. افتح مجلد `android/` في Android Studio (Hedgehog أو أحدث).
2. استخدم JDK 17، ثم اسمح لـ Gradle بمزامنة المشروع وتنزيل الاعتماديات.
3. شغّل إعداد `app` على محاكي أو جهاز Android (Android 7.0 / API 24 أو أحدث).
4. لإنشاء APK تجريبي، اختر **Build > Build APK(s)** في Android Studio.

يتضمن النموذج واجهة عربية من اليمين إلى اليسار، اختيار نوع الحساب، ولوحات أولية للمواعيد والرسائل والملف الشخصي. المحتوى المعروض تجريبي؛ تسجيل الدخول الفعلي والحجوزات والمراسلة وبيانات المرضى تحتاج إلى واجهة خلفية آمنة قبل الاستخدام الحقيقي. لا تُدخل بيانات صحية حقيقية في هذا النموذج.

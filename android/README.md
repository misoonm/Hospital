# طبيب 24/7 — تطبيق Android تجريبي أصلي

مشروع Android أصلي مبني بـ Kotlin وJetpack Compose، وليس WebView. واجهاته عربية من اليمين إلى اليسار، ويحتوي على تسجيل دخول وإنشاء حساب تجريبي ولوحات للرئيسية والمواعيد والرسائل والملف الشخصي.

## التشغيل

1. افتح مجلد `android/` في Android Studio.
2. استخدم JDK 17 وانتظر مزامنة Gradle.
3. شغّل إعداد `app` على محاكي أو جهاز Android 7.0 (API 24) أو أحدث.
4. يمكن إنشاء ملف APK تجريبي من **Build > Build APK(s)**.

## تجربة التطبيق

- من شاشة الدخول، أدخل أي اسم مستخدم وكلمة مرور غير فارغين؛ لا توجد بيانات اعتماد ثابتة.
- أو اختر إنشاء حساب تجريبي، وأدخل الاسم والبريد وكلمة مرور من 6 أحرف على الأقل، ثم حدد نوع الحساب.
- التنقل السفلي يعرض صفحات الرئيسية والمواعيد والرسائل والملف الشخصي.

## حدود النسخة

هذه نسخة عرض محلية فقط، ولا تستخدم Firebase أو أي خادم أو قاعدة بيانات. تسجيل الدخول والتحقق وإنشاء الحساب محاكاة واجهة وليست مصادقة حقيقية؛ البيانات غير متزامنة ولا تُحفظ كحساب دائم. المواعيد والرسائل المعروضة بيانات وهمية. لا تستخدمها مع بيانات صحية حقيقية أو للنشر والاستخدام السريري. يتطلب الإطلاق الفعلي خدمة خلفية آمنة، ومصادقة حقيقية، وسياسات خصوصية وأمان مناسبة.
